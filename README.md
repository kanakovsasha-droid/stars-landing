## При передаче заказчику

Реквизиты в оферте и политике — это лицо, которое торгует и отвечает
перед покупателем. Когда заказчик подключит свою Robokassa, заменить:

- ФИО, ИНН, статус — во всех трёх документах (index, offer, privacy)
- почту для обращений
- контакт поддержки
- юзернейм бота, если он сменится

Держать на боевом сайте оферту от имени разработчика нельзя: продаёт
заказчик, значит и обязательства перед покупателем его.

Цены в таблице `index.html` сверить с теми, что заведены в боте.

## Публикация на GitHub Pages

```bash
cd landing
git init
git add .
git commit -m "landing"
git branch -M main
git remote add origin https://github.com/ПОЛЬЗОВАТЕЛЬ/stars-landing.git
git push -u origin main
```

Дальше в репозитории: **Settings → Pages → Source: main, папка /(root)**.
Через минуту страница поднимется на
`https://ПОЛЬЗОВАТЕЛЬ.github.io/stars-landing/`

## Прописать в боте

```
RULES_URL=https://.../rules.html
PRIVACY_URL=https://.../privacy.html
OFFER_URL=https://.../offer.html
```
