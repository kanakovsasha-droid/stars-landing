# Лендинг для модерации Robokassa

Четыре страницы: главная, оферта, правила, конфиденциальность.
Ссылки на них подставляются в `.env` бота — раздел «Информация» тогда
покажет кнопки «Правила», «Конфиденциальность», «Оферта».

## Не доделано

Оферта писалась под продавца-физлицо, поэтому пункты 9.1 и 9.2 отсылают
к законодательству РФ и ЗоЗПП. Продавец теперь — киргизское юрлицо,
и применимое право нужно согласовать с юристом: либо оставить право РФ
осознанно (для розницы российским покупателям так обычно и делают),
либо переписать раздел.

Цены в таблице `index.html` сверить с теми, что заведены в боте.

## Публикация на GitHub Pages

```bash
cd landing
git init
git add .
git commit -m "landing"
git branch -M main
git remote add origin https://github.com/ПОЛЬЗОВАТЕЛЬ/stars-landing.git
git push -u origin main
```

Дальше в репозитории: **Settings → Pages → Source: main, папка /(root)**.
Через минуту страница поднимется на
`https://ПОЛЬЗОВАТЕЛЬ.github.io/stars-landing/`

## Прописать в боте

```
RULES_URL=https://.../rules.html
PRIVACY_URL=https://.../privacy.html
OFFER_URL=https://.../offer.html
```
